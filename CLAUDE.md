Рабочее имя в коде — `pc_market` (название продукта не выбрано, хочется минималистичное). Стек, схема БД, подробности по фазам и замеры — в `docs/history.md`: читать только нужный раздел.

## Ключевые решения
1. Стек: FastAPI + SQLAlchemy + SQLite (`create_all`, без Alembic: при смене схемы — `ALTER TABLE` или удалить `backend/database.db`), React (Vite) + Tailwind + react-i18next, JWT.
2. Стандартизация = эталонный товар + предложения магазинов (как Oson Apteka).
3. Сортировка предложений по умолчанию — «рекомендованные» (проверенный магазин, наличие, свежесть прайса), по цене — по выбору.
4. МХИК не генерирует ИИ: ИИ определяет категорию, код — из справочника `categories` (tasnif.soliq.uz).
5. Разбор прайса: кэш → правила → ИИ (Gemini, запасной Groq). Цену, артикул и наличие берёт код, не ИИ. «Предположения ИИ» в характеристиках не сохраняются.
6. Anti-Fraud: сначала правила кодом, ИИ — вторым слоем (уровень info). Флаг: тип, уровень info/warning/danger, ключ причины + параметры (тексты в `ru.json`), источник rule/ai. Формулировки мягкие; продавец может оспорить.
7. Импорт: загрузка → разбор → редактируемый предпросмотр → публикация. Повторная загрузка обновляет цены, отсутствующие позиции → «нет в наличии». История цен пишется при каждом изменении.
8. Валюта: продавец выбирает USD или UZS, цена хранится в исходной валюте; покупателю — обе по курсу ЦБ (cbu.uz, раз в день); аналитика в USD.
9. Не делаем: оплату/корзину (только «Связаться»), карты (только район/адрес), чат (телефон/Telegram), мобильную версию.

## Как запустить
- `start.bat` в корне — оба сервера + браузер на http://localhost:5173; `stop.bat` — остановить. Swagger: http://127.0.0.1:8000/docs.
- Вручную: `cd backend` → `.\.venv\Scripts\python.exe -m uvicorn main:app --reload`; `cd frontend` → `npm run dev`. В Claude Code — `.claude/launch.json` (`backend`, `frontend`).
- Тесты: `cd backend` → `.\.venv\Scripts\python.exe -m pytest` (без живых запросов к ИИ и cbu.uz).
- Тестовый продавец: `seller1@example.com` / `seller12345`, магазин «Age Computers» (полный реальный прайс опубликован). Для тестовых email — `@example.com` (`.test` отклоняется).
- Реальный прайс: `F:\claudy\samples\Price of Age Computers (9).xlsx` (вне репозитория, в git не класть).
- ⚠ `--reload` перезапускает сервер при изменении любого `.py` в `backend/` — во время импорта код не править.

## Открытые вопросы
- Сведение карточек: у правил название без слова-типа («Intel Core i5-12400F OEM»), у ИИ — с типом («Процессор Intel Core …») → разный `products.match_key`. Решить в фазе 5 (например, ключ по бренду + модели).
- Замер точности (фаза 7): кэш между прогонами сбрасывать — `scripts/benchmark_parser.py --live` уже работает с пустым кэшем.
- Цена ниже рынка пока почти не срабатывает: в базе один магазин. Для демо (фаза 8) нужны 2–3 магазина.
